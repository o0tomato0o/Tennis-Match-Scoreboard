Step 3: Add Points Formula

Use the formulas below for automated point and ranking calculations in your Google Sheet.

Formula Cheat-Sheet for Google Sheets

Matches Tab Cell I2 (Team A Points):
=IF(ISBLANK(G2), "", IF(G2 > H2, G2 + 1, IF(G2 = H2, G2 + 0.5, G2)))
Matches Tab Cell J2 (Team B Points):
=IF(ISBLANK(H2), "", IF(H2 > G2, H2 + 1, IF(G2 = H2, H2 + 0.5, H2)))
Leaderboard Tab Cell H2 (Total Points for Player ID in A2):
=SUMIF(Matches!$C$2:$D$16, A2, Matches!$I$2:$I$16) + SUMIF(Matches!$E$2:$F$16, A2, Matches!$J$2:$J$16)
Leaderboard Tab Cell D2 (Set Wins for Player ID in A2):
=SUMPRODUCT((Matches!$C$2:$D$16=A2)*(Matches!$G$2:$G$16 > Matches!$H$2:$H$16)) + SUMPRODUCT((Matches!$E$2:$F$16=A2)*(Matches!$H$2:$H$16 > Matches!$G$2:$G$16))
